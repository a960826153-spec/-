# claims-eda
模擬保險理賠資料EDA分析

## 清理決策紀錄 (Data Cleaning Decisions)

- **[組員 A] income_missing 缺值旗標**：新增二元旗標欄位（1: 缺值, 0: 有值），共標記 158 筆缺值，保留低辨識信心（OCR 信心度 < 75 缺值率達 44.6%）之 MAR 遺失信號。
- **[組員 A] income 依險種分群填補**：考量不同保險商品（產品線）投保人之所得水準差異顯著，依險種分組計算收入中位數進行填補，避免整體中位數壓縮組間變異；填補後平均收入由 65.2 萬元調整為 64.3 萬元，缺值數降至 0 筆。
