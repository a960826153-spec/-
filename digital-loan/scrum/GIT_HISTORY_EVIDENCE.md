## 四、歷史紀錄限制

本專題部分 GitHub Issues 為期中整理時補建。

本文件可證明 GitHub 上的提交與期中成果整理紀錄，但不能僅依提交日期還原 Sprint 1、2 的每日實際工作進度。

若需製作 Sprint Burndown Chart，必須另外依據當時的 Sprint 規劃、原始分工、工作完成日期或其他可查證紀錄進行整理。

不得將期中補建 Issues 的日期視為原始 Sprint 完成日期。
